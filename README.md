# 🌱 Daily Garden

Daily Garden is a small web application where you can record your daily activities and mood.

Each entry becomes a card in your personal garden, creating a visual history of your days.

## Features

- Add daily activities
- Select your mood
- Save entries using LocalStorage
- View your garden of entries
